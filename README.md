# Synthesis Registry

Registry and scraper for [Synthesis](https://github.com/Noggog/Synthesis) patcher repositories.

## Data source

The scraper reads GitHub's dependency graph for Synthesis, then reads patcher metadata files containing names and descriptions.

Dependency list: [GitHub dependents](https://github.com/Noggog/Synthesis/network/dependents?package_id=UGFja2FnZS0xMzg1MjY1MjYz)

## Output

`mutagen-automatic-listing.json` contains scraper results consumed by Synthesis.
